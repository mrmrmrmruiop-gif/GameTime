GameTime: setup guide

No accounts or backend needed.

Hosting on GitHub Pages
Create a new GitHub repo (public).
Upload index.html (Add file > Upload files).
Settings > Pages > Deploy from a branch > main / (root) > Save.
After about a minute your site is at https://YOURNAME.github.io/REPO/.
Adding links

Open index.html, find LINKS, and add lines like: {name:"Game", emoji:"🎮", url:"https://..."}, Edit directly on GitHub with the pencil icon.

Chat

Chat runs on the free public ntfy.sh service. Everyone who opens the site joins the room named by CHAT_TOPIC near the top of index.html. Messages are kept for about 12 hours. Change CHAT_TOPIC to start a fresh room, for example if the name leaks. There is no moderation or delete, so only share the site with people you trust.

Notes

Some sites refuse to be framed. For those, use Settings > Open links > New tab, or the "Open in new tab" button in the player.
